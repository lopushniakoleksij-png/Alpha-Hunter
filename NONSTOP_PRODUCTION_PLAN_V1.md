# ALPHA HUNTER — NONSTOP PRODUCTION PLAN v1.0

## Mission

Run Alpha Hunter as a continuous production-and-learning system focused on one economic objective:

> Find, execute, measure, and improve only evidence-backed opportunities that can contribute to repeatable positive expectancy after realistic costs and controlled risk.

Production must not drift into architecture, dashboards, historical plumbing, or speculative model changes that do not materially improve:

**DISCOVERY → DIRECTION → EARLY ENTRY → EXECUTABLE GEOMETRY → EXECUTION QUALITY → RISK → OUTCOME → LEARNING → VERIFIED EDGE**

## 4. PROSPECTIVE PROMOTION GATES

No production direction/entry change is allowed until all relevant gates are satisfied.

### Gate A — Sample maturity

Existing frozen holdout minimums remain:

- >=100 paired eligible observations;
- >=30 symbols;
- >=20 UTC days;
- >=25 LONG;
- >=25 SHORT;
- within the existing maximum study window;
- capture failures remain controlled.

Until this gate is met:

**COLLECT — DO NOT PROMOTE**

### Gate B — Sealed primary analysis

After sample maturity:

- evaluate only through the sealed evaluator;
- do not manually query hidden outcomes;
- apply the preregistered test exactly;
- respect ambiguity/incomplete-data rules;
- no post-hoc threshold editing.

Possible result:

- SUPPORT
- INCONCLUSIVE
- FAILS TO SUPPORT

None of these alone authorizes live trading.

### Gate C — Independent replication

Any supported geometry/direction hypothesis must be replicated on a separate prospective cohort.

No independent replication:

**NO PRODUCTION PROMOTION**

### Gate D — Economic validation

A candidate production change must also show:

- sufficient fill/execution traceability;
- account-observed fee treatment;
- validated slippage / execution-quality model;
- funding where relevant;
- realistic net-R;
- controlled risk;
- no leverage-survivability failure.

Without these:

**NO EXPECTANCY CLAIM**

### Gate E — Controlled production review

Only after A–D:

- engineering council review;
- scientific review;
- failure-mode review;
- safety-contract review;
- smallest reversible production change;
- post-deployment verification.
